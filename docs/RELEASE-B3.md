# Red TV Next b3

- Faster channel opening: reuse the loaded catalog and save compact playback queues.
- Playback recovery for prolonged buffering, decoder fallback, and renewed retry budget after stable playback.
- Optional muted channel preview in Tools > Playback preferences. Highlight a live channel to preview it; selecting it opens full-screen playback. Previews do not add watch history.
- Search across the active source's library, independent of the selected tab/category. Search also refreshes on keyboard submission and when leaving the search box.
- Playback Options hides with the controls. The remote Menu button opens Options.
- Sharing automatically uses an available port when another app occupies 8091. Enter the full address shown on the host TV, including its port, and its pairing code on the second TV. Sharing stops when the host leaves playback. Live synchronization depends on stream timing information.
- New user-supplied RED TV artwork for the app icon and TV banner.

## Updating devices

Install the signed APK over the existing **Red TV Next** app to preserve its local sources, favorites, history, and preferences. The original **Red TV** app is a separate installation; this release does not migrate its settings automatically.

Download: https://github.com/BigR3D210/redtv-next/releases/latest/download/app-release.apk

An installed app may not remain in the Fire TV home screen's recent-app row. Look for Red TV Next in the device's installed-app list.
