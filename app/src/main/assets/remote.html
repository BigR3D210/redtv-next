Red TV remote

Keep the editor screen open on your TV. Use only your trusted home network: this local connection is not encrypted. Closing the TV editor signs out all browsers.

Send a video or laptop file

Paste a playable HTTP(S) media link. For local files, run the included laptop media server and paste its printed link. Streaming sites that need a web browser are not playable links.

Edit active source

Stored credentials and URLs are never sent to this page. Blank fields keep existing values. Saving applies to the active source and reloads the TV catalog.
